# Folio

- This is an independently installable InstinctaZero experiment. Keep the Android
  application ID, signing identity and OAuth callback distinct from the stable app.
  Never copy live pairing tokens or private user databases into this checkout.
- All code written must be bottlenecked by physical reality. The bottleneck is never allowed to be the implementation itself.
  Profile actual work. Do not make an edit appear saved before it is durable.
- Keep the board, arrows, one-tap input and drag-back responsive; preserve
  repertoire markers, candidate moves, comment previews and local editing. Show
  one purpose-specific board panel at a time.
- Use small, focused checks and synthetic positions. Do not use the USB-tethering
  phone for testing. Do not publish private books, saved games or signing keys.
- For a requested release, verify the signed APK from its actual public download
  before sending one concise Telegram bridge notification. If local private
  delivery tools are unavailable, report exactly what remains to the requester.
